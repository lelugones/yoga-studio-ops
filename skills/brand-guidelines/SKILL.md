# Skill: Identidad y Diseño de Marca (Yoga Studio)

## 1. Esencia de Marca
- Personalidad: Serena, cálida, limpia, funcional y libre de saturación visual.
- Voz y Tono: Amable, directo y empático. Los textos deben transmitir calma, no estrés operativo (evitar rojos chillones para alertas normales; usar terracota/ámbar).

## 2. Sistema de Diseño (Tailwind CSS)

### Paleta Cromática
- **Fondo / Lienzo:** `bg-[#FBF9F5]` (Warm Alabaster / Arena suave)
- **Superficie / Tarjetas:** `bg-[#FFFFFF]` con bordes sutiles `border-[#EBE6DD]`
- **Primario (Acción & Énfasis):** `bg-[#3D5A50]` / `hover:bg-[#324B42]` (Eucalyptus Sage - verde botánico apagado)
- **Texto Principal:** `text-[#2A3430]` (Pizarra carbón suave)
- **Texto Secundario:** `text-[#6B7570]` (Salvia neutro)
- **Acentos y Alertas:**
  - Saldo bajo / Alerta: `text-[#C26D43]` / `bg-[#FDF2EC]` (Terracota cálido)
  - Éxito / Presente: `text-[#3D6B52]` / `bg-[#EAF3EE]` (Verde bosque suave)
  - Cupo lleno / Peligro: `text-[#A34343]` / `bg-[#FBEBEB]` (Rojo ladrillo apagado)

### Tipografía
- Títulos: Serif orgánica y moderna (`font-serif`, estilo Playfair Display o Cormorant).
- Interfaz y Datos numéricos: Sans-serif geométrica legible a distancia (`font-sans`, estilo Inter o DM Sans).

### Componentes de UI
- Bordes redondeados cómodos: `rounded-xl` o `rounded-2xl`.
- Sombras mínimas y difusas: `shadow-sm` o `shadow-[0_4px_20px_-4px_rgba(42,52,48,0.06)]`.
- Botones de acción táctil: Altura mínima de 44px (`h-11`) para facilitar uso con una sola mano en recepción.
